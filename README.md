# Eventology Unity Game

This repository contains the **multiplayer tag game prototype** developed by **Eventology** using **Unity** and **Photon PUN 2**. The game is based on the classic playground game *tag*, reimagined as an online 3D experience with third-person controls and flying mechanics.

> 🧩 This project is a customized branch based on the original repository:
> 👉 [https://github.com/NoahCarr938/Tag](https://github.com/NoahCarr938/Tag)

---

## Features

* **Real-Time Multiplayer**: Built with Photon PUN 2 for smooth online play.
* **Third-Person Character Controller**: Fluid movement system using rigidbodies and animation blending.
* **Flying Mechanic**: Players can toggle fly mode to gain an aerial advantage.
* **Tagging System**: Role-swapping logic when players collide.
* **Camera System**: Third-person camera that follows and rotates with the player.

---

## Technologies Used

* **Unity 2020.3 LTS** or later
* **Photon PUN 2 - Free**
* **C#** (Unity scripting)
* **ProBuilder** for level design

---

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Eventolog/unity-game.git
   ```
2. Open the project in **Unity 2020.3 LTS** or later.
3. Import the necessary dependencies, including **Photon PUN 2**.
4. Build and run the project to start testing the game!

---

## Usage

This project features an online multiplayer experience. Once the game is running, players can:

* Join or create a lobby to start playing.
* Use the third-person character controller for movement and flying mechanics.
* Tag other players to swap roles, with the goal of avoiding being tagged.
